This page behaves like a tiny LazyVim session.
Open files from Neo-tree, move between buffers, close buffers,
and use leader bindings.

SPC e       toggle explorer
SPC b n     next buffer
SPC b p     previous buffer
SPC b d     delete current buffer
SPC b o     delete other buffers
SPC w h/j/k/l move window focus
SPC f g     open GitHub
i           insert/edit file
:save       write local changes

-- press Space to start
